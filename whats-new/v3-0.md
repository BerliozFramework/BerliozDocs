# What's new in 3.0

Version 3.0 changes how the framework is developed, not how you use it. Beyond the points below, namespaces, classes
and method signatures are the same as in version 2.

To upgrade, follow [Upgrading from version 2](../getting-started/upgrading.md#upgrading-from-version-2).

## One repository for all components

All Berlioz components are developed, tested and released together in a single repository:
[github.com/BerliozFramework/Berlioz](https://github.com/BerliozFramework/Berlioz).

- Components are always tested together, so a change in one of them cannot silently break another.
- Issues and pull requests are submitted in one place.
- The Composer packages keep their names (`berlioz/config`, `berlioz/router`...) and can still be required one by
  one. Their repositories are now read-only mirrors.

## PHP 8.2

All components require PHP 8.2 or later.

## Updated PSR dependencies

The components follow the latest versions of the PSR packages, in particular `psr/http-message` 2, which adds return
types to the PSR-7 interfaces. If you wrote your own implementation of a PSR-7 interface, add these return types.

See the table of versions in the
[upgrade guide](../getting-started/upgrading.md#updated-psr-dependencies).

## Atlas ORM package removed

The `berlioz/atlas-package` package no longer exists. Use [Hector ORM](../guides/orm/hector.md) instead, or integrate
your ORM yourself.
