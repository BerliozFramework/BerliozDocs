# What's new?

Each page presents the main new features of a minor version, with a short example and a link to the detailed
documentation.

| Version                    | Main new features                                                                        |
|----------------------------|------------------------------------------------------------------------------------------|
| [3.4](whats-new/v3-4.md)   | Work after the response, deferred queues, HTTP `QUERY` method, encrypted SMTP connections |
| [3.3](whats-new/v3-3.md)   | Secured reverse-proxy prefixes, custom form mapping, safer HTTP client redirections      |
| [3.2](whats-new/v3-2.md)   | Redis and fallback cache drivers, database migrations, queue metrics endpoint            |
| [3.1](whats-new/v3-1.md)   | Queue monitoring, stricter router and configuration, many fixes                          |
| [3.0](whats-new/v3-0.md)   | Monorepo, PHP 8.2                                                                        |

These pages are not exhaustive:

- to upgrade your project, follow the [upgrade guide](getting-started/upgrading.md);
- for the complete list of changes, read the
  [changelog](https://github.com/BerliozFramework/Berlioz/blob/3.x/CHANGELOG.md).
