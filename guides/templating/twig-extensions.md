# Twig extensions

Three extensions are provided with the Twig Package:

- `Berlioz\Package\Twig\Extension\AssetExtension`
- `Berlioz\Package\Twig\Extension\DefaultExtension`
- `Berlioz\Package\Twig\Extension\RouterExtension`

## Extension `AssetExtension`

Functions provided:

- `asset()`
- `entrypoints()`
- `entrypoints_list()`
- `preload()`

### Assets configuration

`asset()` and `entrypoints()` read JSON files generated by your asset bundler. Their paths are configured under
`berlioz.assets`:

| Key               | Description                                                                  | Default with **berlioz/http-core**                                |
|-------------------|------------------------------------------------------------------------------|-------------------------------------------------------------------|
| `manifest`        | Manifest file used by `asset()`: maps each asset name to its final path      | `{config:berlioz.directories.app}/public/assets/manifest.json`    |
| `entrypoints`     | Entry points file used by `entrypoints()` and `entrypoints_list()`           | `{config:berlioz.directories.app}/public/assets/entrypoints.json` |
| `entrypoints_key` | Key of the entry points file that contains the entry points, if not the root | `null`                                                            |

### Preload

`preload()` sends a `Link: <...>; rel=preload` response header for the given link, and returns the finalized link.
Parameters are added to the header (`true` adds the parameter without value, `false` and `null` are ignored).
A link is sent only once per response, and nothing is sent once headers are already sent.

```twig
<link rel="stylesheet" href="{{ preload('/assets/css/website.css', {as: 'style'}) }}">
<script src="{{ preload('/assets/js/app.js', {as: 'script', crossorigin: true}) }}"></script>
```

The `preload` option of `entrypoints()` preloads every rendered file, with `as=style` for CSS files and `as=script`
for JS files. An array can be given to add parameters to each preload header:

```twig
{{ entrypoints('website', 'css', {preload: true}) }}
{{ entrypoints('website', 'js', {preload: {crossorigin: true}, defer: true}) }}
```

> 🆕 **Info**: *Since version 3.4*
>
> Every file rendered by `entrypoints()` is preloaded (previously only the first one), and the `Link` header is sent on
> every response. The HTTP/2 Server Push cache (`h2pushes` cookies) has been removed.

> ⚠️ **Warning**: *Deprecated since version 3.4*
>
> The `nopush` parameter is deprecated: HTTP/2 Server Push is no longer supported by browsers. It will be removed in
> version 4.
>
> The `AssetRuntimeExtension::H2PUSH_CACHE_COOKIE` constant and the `AssetRuntimeExtension::setCookie()` method are
> deprecated too: the framework no longer uses them.

## Extension `DefaultExtension`

Filters provided:

- `date_format`
- `truncate`
- `nl2p`: wraps paragraphs in `<p>` and converts line breaks to `<br />`
- `human_file_size`
- `json_decode`
- `basename`

> 🆕 **Info**: *Since version 3.4*
>
> `nl2p` escapes its input before adding its markup, like the Twig `nl2br` filter. To format trusted HTML, mark it
> as safe first: `{{ html|raw|nl2p }}`.

Tests provided:

- `instance of`

## Extension `RouterExtension`

Functions provided:

- `path()`
- `path_exists()`
- `finalize_path()`
